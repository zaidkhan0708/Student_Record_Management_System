 Project Overview
​The Student Record Management System is a Python 3 console-based program designed to handle basic CRUD (Create, Read, Update, Delete) operations for student data. It ensures data integrity by validating unique roll numbers and permissible score ranges.  
​Key Features
​Add Records: Insert new student entries containing Roll Number, Name, Course, and Marks.  
​View Records: Display all stored records in a neat, tabular format.  
​Search Records: Look up specific student details instantly using their unique roll number.  
​Update Records: Modify existing student marks securely via roll number reference.  
​Delete Records: Remove student entries from the system database.  
​Robust Validation:
​Enforces unique roll numbers to prevent duplicate entries.  
​Restricts student marks strictly between 0 and 100.  
​⚙️ Technical Specifications & Concepts
​Language: Python 3  
​Core Concepts Used: Lists, Tuples, Dictionaries, and CRUD logic modularized into separate functions.  
​Architecture: Single-file execution (.py) running directly from the console.  
​📋 Bare Minimum Requirements & Instructions
​Execution: Written entirely in Python 3; execute the script directly via your terminal or command prompt.  
​Data Structures: Utilizes combinations of lists, tuples, and dictionaries to organize data seamlessly.  
​Modular Code: Implements dedicated, separate functions for each individual CRUD operation.
